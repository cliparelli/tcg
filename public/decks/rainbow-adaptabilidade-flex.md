# Adaptabilidade Flex — Rainbow (Todos os Tipos)

Segundo deck Rainbow: altamente flexível, com múltiplas opções de ativação. Cada tipo fornece uma ativação diferente (Magia = leitura, TecSci = reciclagem, Físico = dano, Divino = defesa, Cósmico = escala). Vence pela capacidade de adaptar a estratégia durante a partida.

Personagens variados sem hierarquia clara, deixando a estratégia fluida.
