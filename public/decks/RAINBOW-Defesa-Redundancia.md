# [RAINBOW] Defesa com Redundância — Todos os Tipos

Quarto deck Rainbow: múltiplas camadas de defesa. Cada tipo contribui uma forma diferente de mitigação (Magia = cura, TecSci = stall, Físico = bloqueio, Divino = imunidade, Cósmico = remoção). Vence pelo tempo infinito: sempre há uma defesa disponível.
