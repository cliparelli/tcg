# Swarm Go-Wide — Físico

Deck que preenche todas as Posições do Time rapidamente com múltiplos personagens de baixo custo e os mantém atacando via Flanquear constante. Vence pela superioridade numérica: o oponente não consegue blocar todo ataque simultâneo. Cada unidade é descartável; o que importa é o volume.

Combina personagens genéricos e de baixa vida com **Reviravolta Tática** (Flanquear genérico) para garantir que cada um ataca antes de morrer. **Mireia Passo-Rápido** como líder mantém o fluxo rápido, atacando múltiplas vezes. O jogo é sobre quantidade, não qualidade.
