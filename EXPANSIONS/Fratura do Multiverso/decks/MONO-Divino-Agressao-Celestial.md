# [MONO] Agressão Celestial — Divino

Deck agressivo que desafia a reputação de Divino como puramente defensivo. Personagens de custo alto entram rápido via **Sobrecarga de Núcleo** e atacam com buffs crescentes. Diferente de Swarm, este é "Go Tall" com poder cósmico: poucos personagens poderosos em vez de muitos fracos.

**Rafiel Mão-Que-Protege** como líder intifica a agressão defensiva: protege enquanto ataca. Cada cura é um buff potencial via itens que ganham valor com Vida recuperada.
