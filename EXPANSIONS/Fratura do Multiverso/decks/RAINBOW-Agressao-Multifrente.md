# [RAINBOW] Agressão Multifrente — Todos os Tipos

Terceiro deck Rainbow: agressão de múltiplas frentes. Cada tipo contribui uma forma diferente de dano (Magia = debuff, TecSci = reciclagem ofensiva, Físico = ataque direto, Divino = punição, Cósmico = área). Vence pelo overkill: o oponente não consegue se defender de tanta pressão simultânea.

Foco em personagens de ataque com suporte de itens agressivos.
